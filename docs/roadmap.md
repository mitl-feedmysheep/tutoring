# 작업 순서

완료하면 체크하고, 작업 일지에도 남긴다.

## 0단계. 준비 (사용자)

- [x] GitHub 저장소 생성: https://github.com/mitl-feedmysheep/tutoring
- [x] Cloudflare Tunnel에 `tutoring.intotheheaven.app` → `localhost:3010` 추가
- [x] Doppler 프로젝트 생성: `tutoring` (prd)
- [x] Doppler prd 서비스 토큰 → GitHub 저장소 Secrets에 `DOPPLER_TOKEN`으로 등록
- [x] R2 비공개 버킷 생성
- [x] R2 버킷(`tutoring-prod`) 전용 토큰(개체 읽기 및 쓰기) 발급 → Doppler prd 등록, CORS 설정
- [x] Google Cloud 프로젝트 + OAuth 클라이언트 생성, Doppler에 `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` 등록

## 1단계. 뼈대와 배포 파이프라인

- [x] Next.js 프로젝트 생성, mitl admin 설정 가져오기 (Tailwind, shadcn 설정, ESLint, vitest)
- [x] git 초기화, 첫 커밋, push
- [x] MySQL에 `tutoring` 스키마와 전용 계정 생성 (2단계 시작 때)
- [x] Dockerfile, GitHub Actions 배포 워크플로 (포트 3010)
- [x] 빈 페이지를 실제 도메인에 배포해서 파이프라인 확인

## 2단계. DB 설계와 인증

- [x] DB 스키마 설계 (격리 규칙 포함) → Prisma 마이그레이션
- [x] Doppler prd에 `DATABASE_URL` 등록
- [x] 선생님 계정 생성 스크립트 (첫 관리자 계정 생성 완료)
- [x] 로그인, 학생 초대 링크, 가입, 비밀번호 초기화와 강제 변경
- [x] 어드민 선생님 계정 관리 (시스템 관리자만, ADMIN-05)
- [x] 선생님 범위 강제 계층 + 선생님 간 접근 차단 테스트

## 3단계. 핵심 기능 (여기까지 되면 실제 수업에 사용 시작)

- [x] 웹앱 공통 틀: 하단 탭(수업/공부/MY), 하위 화면 ← 버튼, 에메랄드 색, 수업 탭 인사, MY 탭 (APP-01~09)
- [x] 일정: 슬롯 관리, 예약, 고정 일정, 1시간 전 취소 규칙
  - [x] 어드민: 고정 수업 시간 등록·수정·삭제, 월 달력 슬롯 관리(1회성 추가, 삭제), 월말 슬롯 자동 생성 스케줄러
  - [x] 웹앱: 학생 예약·취소·옮기기, 1시간 전 규칙
  - [x] 웹앱: 학생 고정 일정 고르기·바꾸기 ("이번만 / 앞으로 전부")
  - [x] 어드민: 선생님이 학생 일정 바꾸기(사유) + 변경 이력
- [x] 수업 기록: 완료·결석 체크
- [x] 수업 노트: 선생님 노트, 학생 노트
- [x] 공부 기록: 기록, 달력 뷰, 합계, 사진 첨부(R2)
