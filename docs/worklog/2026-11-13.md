## 사용자가 직접 할 폰 테스트 (미뤄 둠)

PWA 설정(manifest, 아이콘, 아이폰 meta)을 넣은 뒤 사용자에게 다시 안내한다. 지금은 홈 화면에 추가해도 주소창 없는 앱으로 열리지 않아 의미가 적다.

- [ ] 홈 화면에 추가 → 주소창 없이 열리는지 (아이폰, 안드로이드)
- [ ] 하단 탭 수업 → 공부 → MY 이동 후 뒤로 가기(안드로이드 뒤로 버튼)가 탭 사이를 오가지 않는지
- [ ] MY → 비밀번호 변경 → ← 로 MY에 돌아오는지
- [ ] 주소로 `/change-password`에 바로 들어가서 ← 를 누르면 MY 탭으로 가는지 (앱 밖으로 나가지 않음)
- [ ] 아이폰 아래쪽 홈 바에 하단 탭이 가리지 않는지, 위쪽 노치에 제목이 가리지 않는지
- [ ] 수업 탭 인사 "이름님, 문구"가 한 줄로 보이는지

PWA 작업 때 정할 것: 앱 아이콘(사용자 이미지 또는 에메랄드 배경 + 학사모/T), 홈 화면 앱 이름("Tutoring" 유지 여부). 사용자는 예약 작업을 먼저 하기로 했다.
