## 수업 탭 한 화면으로

- 수업 탭이 폰 한 화면을 넘어 아래가 잘렸다 (사용자 지적). 예약은 위 오른쪽 "+ 예약", 고정 일정은 내 수업(전체 보기) 맨 위로 옮겨 다음 수업 카드 + 달력만 남겼다 (APP-02).
- 들어가기 안내를 "10분 전부터 들어갈 수 있어요"로 (사용자 요청). 버튼은 화면에서 시간을 재서 새로 고침 없이 켜고, 앱이 다시 열릴 때도 다시 확인한다. 눌렀을 때 서버가 시간을 다시 확인한다.
- 시안에 내 노트 사진을 "제안"으로 넣었다. DB 변경이 필요해서 사용자 승인 대기.
- 내 노트 사진은 넣지 않기로 했다 (사용자 결정). 사진은 공부 기록에만. DB 변경 없음.
- 수업 탭 제목 자리에 이름 인사("김지은님, 안녕하세요")를 넣었다 (APP-02). 이름에서 성을 떼면 두 글자 성·외국 이름에서 틀릴 수 있어 전체 이름을 쓴다.
- 수업 탭 인사: "안녕하세요", "~님의 수업"은 어색하다는 의견에 따라 "김지은님, Keep it up!"처럼 이름 + 영어 응원 문구로. 문구 12개를 KST 날짜 기준 하루 하나씩 돌린다 (APP-02). 글자 크기는 다른 탭 제목보다 작게 (15px).

## 웹앱 공통 틀

### 한 일

- 하단 탭(`components/app/bottom-tabs.tsx`): 수업 `/`, 공부 `/study`, MY `/my`. 아이폰 홈 바 여백(safe-area) 포함.
- 화면 틀(`components/app/screens.tsx`): `TabScreen`(제목 + 하단 탭), `SubScreen`(← 버튼 + 제목, 하단 탭 없음).
- 뒤로 가기(`components/app/nav.tsx`, `lib/app/nav-depth.ts`): 앱 안에서 쌓은 화면 수를 세서, ← 는 쌓인 게 있으면 뒤로, 없으면 그 화면의 탭으로 간다. 탭 이동은 `replace`라 기록이 쌓이지 않는다.
- 색: 인투디헤븐 웹앱 팔레트(에메랄드)로 바꿨다. 어드민의 indigo 포인트도 emerald로 (사이드바, 일정 달력, 탭).
- 수업 탭: "김지은님, Keep it up!" 인사 (`lib/app/cheer.ts`, KST 날짜마다 문구 바뀜). 내용은 일정 기능 때 채운다.
- 공부 탭: 자리만. MY 탭: 프로필(담당 선생님 이름), 메뉴(준비 중 표시), 비밀번호 변경, 로그아웃.
- 웹앱 비밀번호 변경(강제 변경이 아닐 때)은 MY 탭의 하위 화면으로.
- viewport `viewport-fit=cover`, 상단바 색을 배경색으로.
- 테스트 7개 추가 (총 102개): 응원 문구 날짜 기준, 쌓인 화면 수 계산, 담당 선생님 이름은 자기 선생님 것만.
- 테스트 DB로 띄워 학생·선생님 세션으로 각 화면 응답과 스크린샷 확인.

### 결정한 것과 이유

- 앱 안 기록 수를 직접 센 이유: `history.length`는 앱 밖 기록까지 포함한다. 알림으로 하위 화면에 바로 들어왔을 때 `history.back()`을 부르면 아이폰 홈 화면 앱에서 갈 곳이 없다.
- 담당 선생님 이름은 학생 범위(`studentDb`)로 이름만 읽는다. 선생님 행의 비밀번호 해시 등은 꺼내지 않는다.
