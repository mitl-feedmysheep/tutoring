## 결정한 것

- **구조**: Next.js 하나로 학생 앱과 어드민을 함께 만든다. 이전 서비스처럼 프론트, 백엔드, 어드민을 나누지 않는다. 혼자 운영하기에는 하나가 관리하기 쉽다.
- **멀티테넌트**: mitl의 교회 단위 격리와 같은 방식이지만 한 단계(선생님)로 단순화한다. 기능을 추가하면 친구 선생님도 같이 쓸 수 있고, 학생 데이터는 선생님별로 완전히 분리된다.
- **선생님 등록**: 처음엔 직접 DB에 넣고, 나중에 어드민 기능으로 추가한다. 결제나 셀프 가입은 하지 않는다.
- **학생 가입**: 학생별 1회용 초대 링크 (1시간 유효), 이메일 + 비밀번호 로그인
- **비밀번호 분실**: 선생님이 `12341234`로 초기화하고, 학생은 다음 로그인 때 반드시 변경
- **알림**: 웹 푸시 (PWA 홈 화면 추가 전제)
- **화상 수업**: Google Calendar API로 슬롯마다 Meet 링크 자동 생성
- **기술 스택**: Next.js + MySQL(기존 서버에 별도 스키마) + R2
- **배포**: mitl admin과 같은 방식. Mac mini self-hosted runner → Docker → Doppler → Cloudflare Tunnel

### 결정한 것
- **Next.js 16.4.6 사용** (mitl admin은 16.1.1). 16.1.1에는 미들웨어 우회를 포함한 보안 취약점이 다수 있어서 최신 패치 버전으로 올림. 운영 의존성 취약점 0건.
- Doppler 환경변수는 `--env-file`로 넘김. mitl의 `eval` 방식은 값에 따옴표나 특수문자가 있으면 깨질 수 있음.
- 시스템 npm 10.9.2에 설치 버그가 있어서 로컬 설치는 `npx npm@11 install`로 함. 배포 쪽 `npm ci`는 영향 없음.
