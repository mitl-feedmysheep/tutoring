# 사용자가 나중에 확인할 것

개발이 다 끝난 뒤 한 번에 확인한다 (사용자 결정, 2026-11-13). 새로 생기면 여기에 추가하고, 확인하면 체크한다.
홈 화면 앱으로 확인해야 하는 것이 많아서 PWA(5단계)를 넣은 뒤에 하는 것이 좋다.

## 폰 (아이폰, 안드로이드)

### 앱 틀

- [ ] 홈 화면에 추가 → 주소창 없이 열리는지
- [ ] 홈 화면 아이콘(헤드셋 쓴 곰)과 이름 "Tutoring"이 제대로 보이는지 (아이폰: 공유 → 홈 화면에 추가, 안드로이드: 메뉴 → 앱 설치)
- [ ] 아이폰 홈 화면 앱에서 처음 한 번 로그인하면, 앱을 껐다 켜도 로그인이 유지되는지 (아이폰은 사파리와 홈 화면 앱의 로그인이 따로라서 앱에서 한 번 더 로그인해야 함)
- [ ] 위쪽 상태 표시줄(시간·배터리)이 화면과 겹치지 않고 잘 보이는지
- [ ] 하단 탭 수업 → 공부 → MY 이동 후 뒤로 가기(안드로이드 뒤로 버튼)가 탭 사이를 오가지 않는지
- [ ] MY → 비밀번호 변경 → ← 로 MY에 돌아오는지
- [ ] 주소로 `/change-password`에 바로 들어가서 ← 를 누르면 MY 탭으로 가는지 (앱 밖으로 나가지 않음)
- [ ] 아이폰 아래쪽 홈 바에 하단 탭이 가리지 않는지, 위쪽 노치에 제목이 가리지 않는지
- [ ] 수업 탭 인사 "이름님, 문구"가 한 줄로 보이는지

### 알림

- [ ] 아이폰 사파리(홈 화면 추가 전)에서 MY → 알림 설정을 열면 홈 화면 추가 안내가 나오는지
- [ ] 홈 화면 앱에서 처음 로그인하면 수업 탭에 "알림을 켜 둘까요?" 창이 뜨고, "알림 켜기" → 허용하면 켜지는지
- [ ] "나중에"를 누르면 앱을 다시 열어도 그 창이 다시 뜨지 않는지
- [ ] 홈 화면 앱에서 알림 켜기 → 권한 묻는 창 → 허용 → 스위치가 켜지는지
- [ ] "시험 알림"을 누르면 알림이 오고, 알림을 누르면 알림 설정 화면이 열리는지 (앱을 닫아 둔 상태에서도)
- [ ] 알림을 끄면 시험 알림 버튼이 사라지는지, 다시 켤 수 있는지
- [ ] 로그아웃 후 다시 로그인하면 알림이 꺼져 있는지
- [ ] 안드로이드 크롬에서도 같은지

### 수업

- [ ] 수업 탭(다음 수업 카드 + 달력)이 스크롤 없이 한 화면에 들어오는지
- [ ] 수업 취소 확인창이 홈 바에 가리지 않는지
- [ ] 고정 일정 "이번만 / 앞으로 전부" 확인창이 홈 바에 가리지 않는지

### 노트

- [ ] 한글 키보드로 노트를 쓸 때 엔터를 치면 다음 줄에 "- "가 한 번만 붙는지
- [ ] 빈 "- " 줄에서 엔터를 치면 그 "- "가 지워지는지
- [ ] 노트 칸을 누를 때 화면이 확대되지 않는지
- [ ] 노트를 쓰다 저장하지 않고 ← 로 나갔다가 다시 들어오면 쓰던 내용이 남아 있는지

### 공부 기록

- [ ] 운영에서 사진을 올렸을 때 R2 CORS에 막히지 않는지 (실제 R2로는 아직 안 올려 봄. 막히면 버킷 CORS에 `https://tutoring.intotheheaven.app`, PUT, `Content-Type` 헤더 허용 추가)
- [ ] 사진 버튼을 누르면 카메라 촬영과 앨범 고르기가 둘 다 나오는지
- [ ] 아이폰 사진(HEIC)이 바로 올라가고, 세로 사진이 눕지 않고 바로 보이는지
- [ ] 사진 여러 장을 한 번에 골라 올릴 수 있는지
- [ ] 공부 기록 내용 칸도 엔터를 치면 "- "가 붙는지, 누를 때 확대되지 않는지
- [ ] 사진 크게 보기에서 닫기(×) 버튼이 노치에 가리지 않는지

### 게시판

- [ ] 글 화면에서 댓글 칸을 누르면 키보드 위로 댓글 칸이 올라오고, 쓰는 중에 화면이 확대되지 않는지 (아이폰 홈 화면 앱)
- [ ] 아이폰 홈 화면 앱에서 댓글 칸이 화면 아래 홈 바에 가리지 않는지

### 자료실

- [ ] 어드민에서 PDF를 올릴 때 R2 CORS에 막히지 않는지 (공부 사진과 같은 설정)
- [ ] 아이폰 홈 화면 앱에서 자료를 누르면 PDF가 열리고, "완료"로 앱에 돌아오는지. 한글 파일 이름이 깨지지 않는지
- [ ] PDF 화면에서 공유 → "파일에 저장"이 되는지
- [ ] 안드로이드 크롬에서 자료를 누르면 열리는지 (크롬은 PDF를 바로 보여 주지 않고 내려받을 수 있음)

### 시간 알림 (수업 30분 전, 밤 11시 공부 기록)

- [ ] 수업 30분 전에 선생님 폰과 학생 폰에 알림이 오는지, 누르면 수업 탭이 열리는지
- [ ] 공부 기록을 안 한 날 밤 11시 조금 넘어 알림이 오는지, 누르면 그날 공부 기록 화면이 열리는지 (기록한 날은 안 와야 함)
- [ ] 수업 직전에 배포해도 알림이 (조금 늦게라도) 오는지

### 이벤트 알림 (일정 변경, 슬롯 삭제, 게시판)

- [ ] 학생이 수업을 예약·취소·옮기면 선생님 폰에 알림이 오고, 누르면 어드민 학생 카드가 열리는지
- [ ] 선생님이 학생 수업을 바꾸면 학생 폰에 사유가 함께 오고, 누르면 내 수업 화면이 열리는지
- [ ] 예약된 슬롯을 지우면 학생 폰에 알림이 오는지
- [ ] 게시판 글·댓글이 상대방 폰에만 오는지 (내 폰에는 안 와야 함), 누르면 그 글이 열리는지
- [ ] 여러 줄 알림(고정 일정 여러 개를 바꿀 때)이 아이폰·안드로이드에서 줄바꿈되어 보이는지

### 화상 수업 (Google Meet, 고정 링크)

- [ ] 어드민 > 화상 수업 > 구글 계정 연결 → "확인하지 않은 앱" 화면 → 고급 → 이동 → 캘린더 권한 허용 → "구글 계정을 연결했어요"와 이메일이 보이는지
- [ ] 학생이 예약한 수업 10분 전에 선생님 구글 캘린더에 "Tutoring 영어 수업" 일정과 Meet 링크가 생기는지, 학생에게 초대 메일이 가지 않는지
- [ ] 학생 폰 수업 탭 "들어가기" → Meet가 열리는지 (아이폰 홈 화면 앱, 안드로이드 크롬). Meet 앱이 깔려 있으면 앱으로 열리는지
- [ ] 학생이 앱 가입 이메일과 같은 구글 계정으로 로그인해 있으면 승인 없이 바로 들어오는지. 다른 계정이면 "참여 요청"이 선생님에게 뜨는지
- [ ] 선생님 수업 탭(폰·PC) "들어가기" → 같은 Meet 방으로 들어가는지. PC에서는 새 탭으로 열리는지
- [ ] 같은 수업의 학생 두 명이 같은 방에 들어오는지
- [ ] 링크가 생긴 뒤 선생님이 학생을 그 수업에 넣으면, 그 학생이 들어가기를 누를 때 바로 들어오는지
- [ ] 예약된 슬롯을 지우면 구글 캘린더 일정도 없어지는지
- [ ] 고정 링크로 바꾸고 Zoom 개인 회의실 링크를 넣으면 들어가기가 Zoom으로 열리는지
- [ ] 연결 끊기 → 구글 계정 설정(보안 > 서드 파티 앱)에서 Tutoring 권한이 없어졌는지

## 아이패드

- [ ] 어드민 일정 달력을 스크롤해도 왼쪽 사이드바가 화면 위아래를 꽉 채우는지 (크롬·사파리). 테스트 브라우저에서는 재현되지 않아 실제 기기로 확인 필요
