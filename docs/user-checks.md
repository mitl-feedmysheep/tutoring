# 사용자가 나중에 확인할 것

개발이 다 끝난 뒤 한 번에 확인한다 (사용자 결정, 2026-11-13). 새로 생기면 여기에 추가하고, 확인하면 체크한다.
홈 화면 앱으로 확인해야 하는 것이 많아서 PWA(5단계)를 넣은 뒤에 하는 것이 좋다.

## 폰 (아이폰, 안드로이드)

### 앱 틀

- [ ] 홈 화면에 추가 → 주소창 없이 열리는지
- [ ] 하단 탭 수업 → 공부 → MY 이동 후 뒤로 가기(안드로이드 뒤로 버튼)가 탭 사이를 오가지 않는지
- [ ] MY → 비밀번호 변경 → ← 로 MY에 돌아오는지
- [ ] 주소로 `/change-password`에 바로 들어가서 ← 를 누르면 MY 탭으로 가는지 (앱 밖으로 나가지 않음)
- [ ] 아이폰 아래쪽 홈 바에 하단 탭이 가리지 않는지, 위쪽 노치에 제목이 가리지 않는지
- [ ] 수업 탭 인사 "이름님, 문구"가 한 줄로 보이는지

### 수업

- [ ] 수업 탭(다음 수업 카드 + 달력)이 스크롤 없이 한 화면에 들어오는지
- [ ] 수업 취소 확인창이 홈 바에 가리지 않는지
- [ ] 고정 일정 "이번만 / 앞으로 전부" 확인창이 홈 바에 가리지 않는지

### 노트

- [ ] 한글 키보드로 노트를 쓸 때 엔터를 치면 다음 줄에 "- "가 한 번만 붙는지
- [ ] 빈 "- " 줄에서 엔터를 치면 그 "- "가 지워지는지
- [ ] 노트 칸을 누를 때 화면이 확대되지 않는지
- [ ] 노트를 쓰다 저장하지 않고 ← 로 나갔다가 다시 들어오면 쓰던 내용이 남아 있는지

## 아이패드

- [ ] 어드민 일정 달력을 스크롤해도 왼쪽 사이드바가 화면 위아래를 꽉 채우는지 (크롬·사파리). 테스트 브라우저에서는 재현되지 않아 실제 기기로 확인 필요
